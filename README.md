# Ticket Booking System

A full-stack movie and concert ticket booking platform supporting customers, organisers, and administrators.

## Core Features

- User authentication and role-based access
- Venue and seat layout management
- Movie and concert event management
- Multiple shows per event
- Real-time seat availability
- Temporary seat holding
- Double-booking prevention
- Payment gateway integration
- Booking and cancellation
- Waitlist management
- Automatic waitlist seat allocation
- QR ticket generation
- Email notifications
