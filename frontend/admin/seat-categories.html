Database Design

Category definitions belong to the venue.

A category describes a logical group such as General, Premium or VIP. Individual Seat records reference the category.

Pricing Rule

Admin does not set ticket prices here.

Organisers assign prices to venue categories for each Show, so Premium can have different prices across different shows.

Safe Deletion

Categories with assigned seats are protected.

Reassign or remove those physical seats through Seat Layout before deleting the category.
